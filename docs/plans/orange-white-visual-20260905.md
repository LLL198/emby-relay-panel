# 全站橙白视觉改版

## 目标与边界

统一认证页、用户线路页和后台的橙白视觉，增强卡片、图标、地球与动效质感。保留全部内容、表单顺序、字段、接口、统计项及操作流程，不新增功能。日志保持黑底，成功和错误保持语义色。

## 实现决策

- 在 panel.py 内统一视觉变量与基础组件，由认证、后台及 uniproxy.py 实际用户模板共用；直接替换旧页面样式，不叠加主题补丁。保留无关的旧常量。
- 暖白画布、白色卡片、深橙主操作与浅橙装饰，保留现有亮暗主题偏好；暗色使用暖黑画布和橙色强调。
- 用内嵌 SVG 统一导航与展示图标；保留现有地球，调整颜色及减少动态效果模式。
- 使用轻微悬停、一次性淡入及静态光晕，不增加依赖或网络资源。
- 桌面、平板、手机可读，宽表格独立滚动，长文字可换行；装饰不拦截交互。
